      Converte cada célula e grava cada linha com um comando próprio.
    \end{painel}}{%
    \begin{painel}{em lote (\textit{batch})}{estratégia atual da ferramenta}
      Converte uma coluna inteira de uma vez e grava muitos registros por comando.
    \end{painel}}
  \onslide<2->{%
  \medskip
  \footnotesize\destaque{Modelo de execução}\enspace
  {\scriptsize\color{black!60} (\texttt{-{}-execution}) quando os dados ocupam a memória}\par
  \smallskip
  \fator{execucao}{%
    \begin{painel}{materialização}{\texttt{materialize}}
      Carrega a fonte inteira na memória e só então processa. O pico de memória cresce
      com o tamanho do arquivo.
    \end{painel}}{%
    \begin{painel}{fluxo (\textit{streaming})}{\texttt{stream}, o padrão em importações
        reais}
      Lê o arquivo em blocos e grava cada bloco antes de ler o próximo. O pico de memória
      fica perto de um bloco.
    \end{painel}}}
  \onslide<3->{%
  \medskip
  \footnotesize Os dados gravados são os mesmos nos dois casos. Muda o custo, que a
  avaliação mede.\par}
  \endgroup
\end{frame}
