## English

**PolyglotImportCSV 2.0.0** has a single write strategy and a stricter
connection file.

### Breaking changes

- **`--strategy` was removed.** The tool always converts types column by column
  and writes in batches. Remove `--strategy optimized` from your scripts; a
  command that still passes it is rejected. The row-at-a-time strategy
  (`naive`) remains available in version 1.1.0.
- **`connection` is required** in every DBMS block of `dbms_config.json`. A
  block without it is rejected when the file is validated.
- **Benchmark results** no longer have a `strategy` column. Move an old
  `benchmark_results.csv` aside before appending new runs to its folder.
- **Benchmark scripts** lost `--strategies` (`scripts/run_benchmarks.py`,
  `scripts/run_benchmarks_100k.py`) and `--strategy`
  (`scripts/benchmark_tracemalloc_ab.py`). Resuming a checkpoint that contains
  `naive` runs is refused.

## Português (BR)

O **PolyglotImportCSV 2.0.0** tem uma única estratégia de escrita e um arquivo
de conexão mais rigoroso.

### Mudanças incompatíveis

- **A opção `--strategy` foi removida.** A ferramenta sempre converte os tipos
  coluna a coluna e grava em lotes. Retire `--strategy optimized` dos seus
  scripts; um comando que ainda a passe é recusado. A estratégia linha a linha
  (`naive`) continua disponível na versão 1.1.0.
- **`connection` é obrigatório** em todo bloco de SGBD do `dbms_config.json`.
  Um bloco sem ele é recusado na validação do arquivo.
- **Os resultados de benchmark** não têm mais a coluna `strategy`. Mova um
  `benchmark_results.csv` antigo antes de acrescentar execuções novas na pasta
  dele.
- **Os scripts de benchmark** perderam `--strategies`
  (`scripts/run_benchmarks.py`, `scripts/run_benchmarks_100k.py`) e
  `--strategy` (`scripts/benchmark_tracemalloc_ab.py`). Retomar um checkpoint
  que contenha execuções `naive` é recusado.
