## English

**PolyglotImportCSV 2.0.1** makes benchmark output refuse a results file with
other columns before it writes or runs anything.

### Fixes

- **`--benchmark`** checks the header of `benchmark_history.csv` before writing
  anything. If the file has other columns, the run fails with "CSV header
  mismatch" and no new `benchmark_*.json` is left in the folder.
- **`scripts/run_benchmarks.py`** (source checkout) checks
  `benchmark_results.csv` in the `--out` folder before it runs the matrix. If
  the header is old, it stops at once with exit code 2 instead of failing
  after the last run. The `benchmarks/` folder keeps the report's campaigns
  with the old header, so pass `--out` with another folder for new runs.

## Português (BR)

O **PolyglotImportCSV 2.0.1** faz a saída de benchmark recusar um arquivo de
resultados com outras colunas antes de gravar ou rodar qualquer coisa.

### Correções

- **`--benchmark`** confere o cabeçalho do `benchmark_history.csv` antes de
  gravar qualquer coisa. Se o arquivo tiver outras colunas, a execução falha
  com "CSV header mismatch" e nenhum `benchmark_*.json` novo fica na pasta.
- **`scripts/run_benchmarks.py`** (no código-fonte) confere o
  `benchmark_results.csv` da pasta de `--out` antes de rodar a matriz. Se o
  cabeçalho for antigo, ele para na hora com código de saída 2, em vez de
  falhar depois da última execução. A pasta `benchmarks/` guarda as campanhas
  do relatório com o cabeçalho antigo; para execuções novas, passe `--out` com
  outra pasta.
